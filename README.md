## Graceful degradation and service workers

Graceful degradation means building an app so it works best with modern features, but still works in a basic way if those features fail or aren’t available like when there’s no internet. Service workers help with this by saving files and data in a cache. If the network is slow or offline, the app can still load saved content instead of completely breaking.
